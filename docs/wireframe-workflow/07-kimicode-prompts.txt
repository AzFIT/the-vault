PROMPT 1 — APP SHELL & NAVIGATION
CONTEXT: 01-app-map-and-architecture.txt
--------------------------------------------------------------------------------
Build the app shell for a personal-training web app (React + TypeScript +
Tailwind + React Router, BrowserRouter).

Requirements:
- Pure black (#000000) background for all app pages; white/gray text only;
  one gold accent color [#d4af37] used sparingly (badges, active states, CTAs).
- Left sidebar, 240px, fixed: logo at top, nav items DASHBOARD, SHEETS,
  ANALYTICS, COACH, PLAN SUMMARY (uppercase, letter-spaced, 12px); a "STAFF"
  divider; an ENQUIRIES item with a gold count badge showing new enquiries.
- CLIENT VIEW / COACH VIEW toggle at the bottom of the sidebar that navigates
  to /dashboard or /coach respectively.
- Top bar inside the content area: page title on the left; on the right a
  search button that opens a ⌘K/Ctrl+K command palette (fuzzy search over
  pages, clients, and programs; arrow keys + Enter to navigate; ESC and
  backdrop click to close), a notifications bell with a dropdown (mock items,
  gold dot on unread, "mark all read"), and a user chip with initials monogram.
- Routes: /dashboard /sheets /analytics /coach /plan-summary
  /admin/enquiries, plus a styled 404 page for everything else. Lazy-load each
  page with a centered loading spinner.
- Sidebar collapses to a hamburger overlay on mobile.
Build only the shell with placeholder page bodies; real pages come next.

PROMPT 3 — TRACKING SHEETS (spreadsheet view)
CONTEXT: 02 + 05-sheets-view-explained.txt
--------------------------------------------------------------------------------
Build the /sheets page: a spreadsheet-grade tracking grid with three tabs —
Daily Tracking, Workouts, Nutrition.

- Grid behavior: click a cell to edit inline; Arrow keys / Tab / Shift-Tab /
  Enter move between cells like Excel; Escape cancels; Enter commits.
- Header bar: Previous week / Next week navigation, week label, "Add row",
  "Export CSV" (downloads current tab), and a "Saved · just now" indicator.
- Daily tab: rows = days of week; columns: Weight, Steps, Sleep, Calories,
  Protein, Carbs, Fat, Notes.
- Workouts tab: rows = exercises; columns: Exercise, Sets, Reps, Load, RPE;
  live-recompute total weekly volume in the footer.
- Nutrition tab: rows = meals; columns: Meal, Calories, Protein, Carbs, Fat;
  user can add/delete custom rows.
- All edits persist to localStorage under one key and are restored on reload;
  a demo reset button clears it.
- Styling: pure black, thin #232323 borders, monospace numbers, gold focus
  ring on the active cell.

PROMPT 5 — PLAN SUMMARY (Blueprint engine)
CONTEXT: 02/03 plan-summary sections
--------------------------------------------------------------------------------
Build a /plan-summary page: a calorie/macro plan generator.

- Left: sticky input console — age, sex, height, weight, body-fat % (optional),
  activity level (preset ×1.4 for office worker), goal (cut/recomp/maintain),
  pace (conservative/standard/aggressive).
- Engine (pure function, no storage):
    BMR = Mifflin-St Jeor; if body-fat % given use Katch-McArdle.
    TDEE = BMR × activity factor.
    Deficit by pace: 15% / 20% / 25%, clamped to a minimum-calorie floor.
    Protein 2.0 g/kg, fat 0.8 g/kg, remainder carbs.
    Include an optional diet-break week every [N] weeks.
- Right: a branded "report document" that updates live: calorie ladder
  (BMR → TDEE → target), macro cards, a 4-phase roadmap, and one sample meal
  day hitting the macros. Print stylesheet so it prints/exports to PDF cleanly
  (WYSIWYG).
Keep the engine in its own file as pure functions with unit-testable outputs.

PROMPT 7 — ENQUIRY FORMS + STAFF INBOX
CONTEXT: 03 + 04-actions-buttons-directory.txt + 06-data-model-and-connections.txt
--------------------------------------------------------------------------------
Build a two-tier enquiry system:

FORMS (modal, opened from pricing cards):
- Tier A (short-term passes: Day / Week / 1-Month) → routed to RECEPTION.
  Fields (9): name, phone, email, preferred contact method (WhatsApp/call/
  email), goal, training experience, preferred days/times, how did you hear
  about us, message (optional).
- Tier B (long-term: 6-Month / 12-Month / Autopay) → routed to SENIOR STAFF.
  Fields (13): all Tier A fields plus occupation, budget confirmation, start
  date, and commitment acknowledgment checkbox.
- Validation: submit button always enabled; on submit with invalid fields show
  inline errors; also show errors on blur (touched). Real <label htmlFor> on
  every field. On success: save the enquiry (localStorage now; one function,
  submitEnquiry(), is the swap point for a real DB later), fire a window event
  'enquiries-changed', show a success toast.

INBOX (/admin/enquiries, staff-only page in the app shell):
- Header: total + new counts, "Export CSV" button.
- Filter tabs: ALL / RECEPTION / SENIOR / NEW ONLY.
- Card list: gold route pill (RECEPTION/SENIOR), time-ago, name, contact
  method, gold dot if new.
- Clicking a card opens a right detail drawer: all submitted fields, a WhatsApp
  button (wa.me link with digits-only phone), "Copy details", "Mark as
  contacted". ESC/backdrop closes.
- The sidebar ENQUIRIES badge listens to the 'enquiries-changed' event and
  updates live without refresh.
