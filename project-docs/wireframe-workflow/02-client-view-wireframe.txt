PAGE: /plan-summary — PLAN SUMMARY (client reads own plan)
──────────────────────────────────────────────────────────
Clients see the branded report their coach generated:
calorie targets → macro split → roadmap → training template →
sample meal day → rules → FAQ → signature block.
[Generate PDF] → window.print() with ink-friendly print.css
(white paper, black ink, app chrome hidden).
NOTE: in this build the page ALSO shows the coach input console
(demo). In your app, gate the console to trainers only; clients
get read-only report via RLS.
